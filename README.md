# OWASP SREC CTF 2026 — Writeups

A collection of my solutions, technical writeups, and key learnings from the **OWASP SREC CTF 2026**. This repository documents the methodologies, tools, commands, and techniques used to solve challenges across multiple cybersecurity domains.

## About the CTF

The OWASP SREC CTF is a cybersecurity competition designed to test practical skills in areas such as web exploitation, cryptography, reverse engineering, digital forensics, and Open-Source Intelligence (OSINT).

My goal with this repository is to document my problem-solving process, strengthen my technical understanding, and maintain a reference for future CTF challenges.

## Challenge Categories

| Category | Focus Areas |

## Writeup Format

Each challenge writeup aims to include:

1. Challenge information and objective.
2. Step-by-step methodology.
3. Commands, payloads, and tools used.
4. Technical explanation of the vulnerability or solution.
5. Final flag, where appropriate.
6. Key takeaways and lessons learned.
